12Every control on the dashboard

Start the dashboard with python -m rescue serve and open the address it prints. Setup is on the left, the 3-D view in the middle and the details on the right. Changing the building or the damage creates a new building. Every other change restarts the mission in the same building, so you can compare settings fairly. A mission waits for Start.

12.1 Setup panel (left)

ControlOptionsWhat changes in the robots' behaviour
Buildingoffice, apartments, hospital, school, parking, warehouse, open test groundA new building of that type (chapter 3). Layouts change how useful each coverage pattern is: long corridors favour frontier exploration, open halls the lawnmower.
Damagelight, moderate, severeMore collapsed walls, rubble and buried victims (10/25/45 % of interior walls collapse; 20/40/60 % of victims partly buried; up to 20 % under thick rubble). Hidden for the test ground, which is never damaged.
New random buildingbuttonSame type, new seed, so a different layout. Hidden for the test ground.
Obstacle editor (test ground only)tall blocks, walls, low crates · Edit layout · Add / Remove · Undo / Default / Clear all · obstacle listPress Edit layout and pick a tool. With Add, a click on free floor places the chosen obstacle (a green ghost shows where; red means the spot is taken). With Remove, the obstacle under the mouse turns red and a click deletes it; it is picked on its 3-D shape, so a tall block can be clicked anywhere. The list shows every obstacle with its size and position: hovering a row highlights it, ✕ deletes it. A click only counts if the mouse did not move, and double-clicks are ignored, so nothing is added twice. Editing is only possible before the mission: Start ends it, and while a mission runs the layout is locked (Restart to edit). Changing the layout never moves the victims. A low crate lies under the LiDAR's scan plane, so only the depth camera close up or the bumper finds it. Obstacles that would seal off part of the ground are refused.
Number insideUnknown / Known (+ how many, 1–16)Unknown (realistic): 4–12 hidden victims, and the robots search everything. Known: they stop and go home once that many are confirmed (a false alarm can make them stop early).
Robots1–8Team size. Patterns split the building into that many rectangles; strategies spread that many robots.
Strategycoordinated, partition, greedy, randomWho takes which frontier or sighting (8.5). With lawnmower or spiral: used for the mop-up after the patterns.
RunsRepeat / VaryRepeat: same settings, the same mission move for move. Vary: the same building, but new random numbers for sensor noise, tie-breaks, RRT* samples and ants, so paths differ.
Path plannerDijkstra, A*, RRT*, ant colonyThe route to each goal (chapter 9). Goals are chosen the same way whatever planner is selected.
Coveragefrontier, lawnmower, spiralHow space is swept (8.4). Lawnmower and spiral show each robot's dashed pattern and its track.
ObstaclesFollow route / DWAFollow the route and wait for teammates, or choose each move with the Dynamic Window Approach (10.2).
RevisitsAllowed / AvoidAvoid: every cell costs 0.3 extra per earlier team visit (up to 5), so routes prefer fresh ground (10.6).
Dead endsRecover / OffDetect loops and blockages, back off and put the goal on a 60 s tabu list (10.5). Off shows what happens without it.
Speed0.2–1.5 m/sFaster robots finish sooner, but the cameras still look once per second, and motor losses grow with speed².
Batteryunlimited, 10…1 Wh, different per robotEnergy-aware task choice, turning home in time, recharging (chapter 11). Different per robot shows one choice per robot.
When lowRecharge / Stay / Run emptyRecharge: go home in time, charge at 60 W and go back out. Stay: go home in time and stay. Run empty: ignore the battery, take any task, and stop exactly where the battery dies, without coming back.
Sensors on the robotsCombined / Vision + Thermal / LiDARCombined: the LiDAR maps, the cameras find people. Vision + Thermal: no LiDAR, so the map grows only where the depth camera looks. LiDAR: no camera, so the building gets mapped but nobody can be found.
Camera / LiDAR range2–8 m / 3–20 mHow far each sensor reaches. The camera range also sets the lawnmower's lane spacing.

12.2 The 3-D view (middle)

  • Show as: Combined (the building as it is, plus findings), LiDAR (only what the lasers know: violet where beams hit), Thermal (only what the thermal cameras measured, hatched where nobody looked). Keys 1 2 3.
  • Camera views: overview, top-down, follow the selected robot. Drag to rotate, right-drag to move, scroll to zoom, double-click to select and zoom.
  • Layers: victim flags, fog over unmapped/unsearched floor, robot paths and goals, the strategy drawn on the floor (8.5), coverage patterns, where each robot has driven, camera cones, sightings and false alarms, zones, the planner search of the selected robot (cells examined, RRT* tree, ant trails), and repeat visits.
  • Legend: what every colour means in the current picture.
  • Transport: Start / Pause, +1 s (one step), speed 1×–30× simulated seconds per real second, Restart.

Presets in the address bar

Any setup can be put in the URL, which is handy for demos and tests:

http://localhost:8001/?building=plain
  &coverage=spiral&robots=2
  &planner=astar&battery_each=1.5,3
  &recharge=1&view=top&autostart=1
  &speed=12&seed=42

Other keys: damage, sensors, show, known, victims, strategy, avoidance, revisit=0.3, deadend=0, rspeed, battery, camrange, lidarrange, density, vary=1, tab, legend=1.

A good first experiment

Open test ground, 1 robot, Coverage = Spiral, Speed 30×, Layers: coverage patterns + where each robot has driven. Watch the robot follow the rings, skip a waypoint on a victim and check a sighting. Then switch the planner to RRT* and watch the any-angle routes, or set Battery = 1.5 Wh to watch it go home, charge and resume.
