RescueSim
Multi-Robot Search & Rescue Simulator · LiDAR · RGB-D · Thermal
How a team of robots searches an unknown, damaged building for people, explained from first principles, down to the code

What this guide covers. The simulated world, the sensors (LiDAR, colour camera, thermal camera), the maps the robots build, the machine-learning detector, how every decision is made (coverage patterns, team strategies, route planners), how robots react to obstacles, dead ends, teammates and flat batteries, how reliable the whole thing is, every control on the dashboard, the software architecture, and the questions an interviewer is likely to ask.

Written for readers new to robotics. Every number in this guide comes from the project's own code (rescue/) and from measurements made with it (scripts/, results/). Where the simulation simplifies reality, the guide says so.

How to read this guide

Chapters 1–2 give you the vocabulary. Chapters 3–7 explain what the robots can know about the world and how. Chapters 8–11 explain how they decide and act, which is the heart of the project. Chapters 12–15 connect it to the dashboard, the code and its limits, and chapter 16 is for interview practice. Coloured boxes appear throughout:

  • In simple words: the idea without jargon.
  • Where in the code: the file and function that implement it.
  • Interview tip: how to say it well.
  • Limitation: where the simulation is simpler than reality.
